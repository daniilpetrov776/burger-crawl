# ParserCoordinator - Параллельный парсинг

Координатор для параллельного запуска нескольких парсеров с автоматическим распределением индексов ресторанов.

## Проблема

При последовательном парсинге нескольких ресторанов процесс занимает много времени. Параллельный запуск ускоряет процесс, но требует координации, чтобы:
- Каждый инстанс парсил только свой набор ресторанов
- Не было дубликатов (один ресторан не парсится дважды)
- Все рестораны были обработаны

## Решение

`ParserCoordinator` распределяет индексы ресторанов между инстансами по кругу:

- **Инстанс 0**: индексы 0, 3, 6, 9, ...
- **Инстанс 1**: индексы 1, 4, 7, 10, ...
- **Инстанс 2**: индексы 2, 5, 8, 11, ...

## Использование

```typescript
import { ParserCoordinator } from './parser/index.js';

// Создаем координатор
const coordinator = new ParserCoordinator({
  totalRestaurants: 10,      // Всего ресторанов для парсинга
  parallelInstances: 3,      // Количество параллельных инстансов
  startIndex: 0              // Начальный индекс (по умолчанию 0)
});

// Фабрика для создания парсера
function createParser(startIndex: number): BaseParser {
  return new BaseParser(
    { url: 'https://burgerkingrus.ru/' },
    new BurgerKingPageParser(),
    {
      setup: new BurgerKingSetup(),
      restaurantIndex: startIndex
    }
  );
}

// Запускаем параллельный парсинг
const { results, processedIndices, errors } = await coordinator.runParallel(createParser);

// Объединяем результаты
const combinedResult = coordinator.combineResults();
```

## Гарантии

1. **Уникальность**: Каждый ресторан парсится только одним инстансом
2. **Полнота**: Все рестораны из указанного диапазона будут обработаны
3. **Отказоустойчивость**: Ошибка в одном инстансе не останавливает другие
4. **Отслеживание**: Все обработанные индексы и ошибки сохраняются

## Распределение индексов

При `totalRestaurants: 10` и `parallelInstances: 3`:

- Инстанс 0: [0, 3, 6, 9]
- Инстанс 1: [1, 4, 7]
- Инстанс 2: [2, 5, 8]

## Результаты

Метод `runParallel()` возвращает:
- `results`: массив результатов парсинга для каждого ресторана
- `processedIndices`: список обработанных индексов
- `errors`: массив ошибок с указанием индекса ресторана
